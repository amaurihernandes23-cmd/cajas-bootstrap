APRENDE CSS

Especificidad en CSS

Aprende cómo funcionan las prioridades de los estilos y cómo controlar el diseño de tus páginas web.

01 - Concepto

¿Qué es la especificidad?

La especificidad es un mecanismo de CSS que permite al navegador decidir qué regla de estilo aplicar cuando varios selectores afectan al mismo elemento.

Cuanto mayor sea la especificidad de una regla, mayor será su prioridad frente a otras reglas de la misma categoría de importancia en la cascada.

02 - Funcionamiento

¿Cómo funciona?

El navegador analiza las reglas CSS y determina cuáles pueden aplicarse a cada elemento HTML.

  • Revisa las reglas que coinciden.
  • Considera la importancia de las reglas.
  • Compara la especificidad.
  • Si existe empate, considera el orden.
03 - Prioridad

Niveles de especificidad

Los selectores tienen diferentes pesos:

  • ID: mayor peso.
  • Clases: peso intermedio.
  • Elementos: menor peso.
  • Universal (*): peso cero.

Los estilos en línea también tienen una especificidad elevada.

04 - Selectores

Selector ID

Se identifica utilizando el símbolo #. Tiene más especificidad que una clase o un selector de elemento. 

#titulo {
    color: blue;
}

Se recomienda utilizar identificadores únicos.

05 - Selectores

Clases y pseudoclases

Las clases se identifican con un punto. También se incluyen los selectores de atributos y las pseudoclases. 

.boton {
    background: blue;
}

.boton:hover {
    background: green;
}
06 - Selectores

Elementos HTML

Los selectores de elementos permiten aplicar estilos directamente a las etiquetas HTML. 

p {
    color: gray;
}

h1 {
    font-size: 30px;
}

Su especificidad es menor que la de las clases y los identificadores.

07 - Selectores

Selector universal

El selector universal se representa con el símbolo * y permite seleccionar todos los elementos. 

* {
    margin: 0;
    padding: 0;
}

No aporta especificidad.

08 - Importancia

Regla !important

La declaración !important cambia la prioridad de una declaración dentro de la cascada CSS. 

p {
    color: red !important;
}

Se recomienda utilizarla con precaución.

09 - Ejemplo

Comparación de selectores

Observa cómo se comparan diferentes selectores que afectan al mismo párrafo. 

p {
    color: blue;
}

.texto {
    color: green;
}

#mensaje {
    color: red;
}

Si los tres selectores coinciden y tienen la misma importancia, gana el selector ID.

10 - Recomendaciones

Consejos para escribir mejor CSS

  • Organiza y comenta tu código.
  • Utiliza clases para los estilos.
  • Evita selectores demasiado específicos.
  • Evita utilizar !important innecesariamente.
  • Mantén una estructura ordenada.
  • Utiliza metodologías como BEM.

Un buen CSS debe ser fácil de entender, modificar y mantener.
