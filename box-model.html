Box Model en CSS

Aprende cómo funciona el modelo de caja y cómo controlar el espacio, tamaño y distribución de los elementos de una página web.

01 - Concepto

¿Qué es el Box Model?

El Box Model o modelo de caja es uno de los conceptos fundamentales de CSS. Establece cómo se representa cada elemento HTML dentro de una página web.

Cada elemento se comporta como una caja que contiene diferentes áreas encargadas de controlar su tamaño y separación.

02 - Estructura

Partes del modelo de caja

El modelo de caja está formado por cuatro partes principales:

  • Content: contenido del elemento.
  • Padding: espacio interior.
  • Border: borde de la caja.
  • Margin: espacio exterior.

Todas estas partes trabajan juntas para determinar el espacio que ocupa un elemento.

03 - Contenido

Content

El content es el área donde se encuentra el contenido principal del elemento, como texto, imágenes o información.

Sus dimensiones se pueden controlar utilizando las propiedades width y height. 

.caja {
    width: 300px;
    height: 150px;
}
04 - Espaciado

Padding

El padding es el espacio interior que existe entre el contenido de un elemento y su borde.

Permite separar el contenido del borde y mejorar la presentación visual. 

.caja {
    padding: 20px;
}

.caja {
    padding-top: 10px;
    padding-bottom: 15px;
}
05 - Bordes

Border

El border es el borde que rodea el contenido y el padding de una caja.

Se puede modificar su grosor, estilo y color. 

.caja {
    border: 2px solid blue;
    border-radius: 10px;
}
06 - Espaciado

Margin

El margin es el espacio exterior que separa una caja de otros elementos de la página.

Permite controlar la distancia entre diferentes componentes. 

.caja {
    margin: 20px;
}

.caja {
    margin-top: 30px;
}
07 - Dimensiones

Width y Height

Estas propiedades permiten establecer el ancho y la altura del contenido de un elemento. 

.caja {
    width: 400px;
    height: 200px;
}

También se pueden utilizar porcentajes y otras unidades de medida.

08 - Dimensiones

Max-width y Min-width

Estas propiedades permiten establecer límites para el ancho de un elemento. 

.contenedor {
    max-width: 1000px;
    min-width: 250px;
    width: 100%;
}

Son muy útiles para crear páginas adaptables a diferentes pantallas.

09 - Organización

Box-sizing

La propiedad box-sizing determina cómo se calcula el ancho y alto total de un elemento. 

* {
    box-sizing: border-box;
}

Con border-box, el padding y el borde se incluyen dentro del ancho y alto definidos.

10 - Comparación

Content-box y Border-box

Son los dos valores más utilizados de la propiedad box-sizing.

Content-box:

.caja {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid;
}

Border-box:

.caja {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid;
}
11 - Espaciado

Margin y Padding

Aunque ambas propiedades controlan espacios, tienen funciones diferentes.

  • Margin: separa elementos entre sí.
  • Padding: separa el contenido del borde.
.caja {
    margin: 20px;
    padding: 20px;
}
12 - Ejemplo

Ejemplo completo del Box Model

Podemos combinar todas las propiedades para definir el tamaño y la separación de una caja. 

.caja {
    width: 300px;
    height: 150px;
    padding: 20px;
    border: 3px solid blue;
    margin: 25px;
    box-sizing: border-box;
}
13 - Diseño

Border-radius

La propiedad border-radius permite redondear las esquinas de una caja, creando diseños más modernos. 

.caja {
    border-radius: 15px;
}

.caja-redonda {
    border-radius: 50%;
}
14 - Diseño

Overflow

La propiedad overflow controla qué sucede cuando el contenido supera el espacio disponible dentro de una caja. 

.caja {
    width: 200px;
    height: 100px;
    overflow: auto;
}
  • visible: muestra el contenido.
  • hidden: oculta el exceso.
  • scroll: agrega desplazamiento.
  • auto: lo agrega cuando es necesario.
15 - Importancia

Importancia del Box Model

El modelo de caja permite organizar correctamente los elementos de una página y controlar el espacio que ocupa cada uno.

Es fundamental para construir diseños ordenados, equilibrados y adaptables.

16 - Recomendaciones

Consejos para trabajar con Box Model

  • Utiliza box-sizing: border-box.
  • Controla el padding de los elementos.
  • Utiliza margin para separar las cajas.
  • Define correctamente width y height.
  • Utiliza max-width para diseños adaptables.
  • Controla el overflow del contenido.

Comprender el Box Model es fundamental para diseñar páginas web organizadas, profesionales y adaptables.
