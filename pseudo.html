Pseudoclases y Pseudoelementos

Aprende a utilizar los estados y las partes específicas de los elementos HTML mediante CSS.

01 - Concepto

¿Qué son las pseudoclases?

Las pseudoclases son palabras clave que permiten aplicar estilos a un elemento cuando se encuentra en un estado determinado o cumple una condición específica.

Por ejemplo, permiten cambiar el aspecto de un botón cuando el usuario coloca el cursor encima. 

button:hover {
    background: blue;
    color: white;
}
02 - Funcionamiento

¿Cómo funcionan?

Las pseudoclases se escriben utilizando dos puntos después del selector. El navegador identifica el estado del elemento y aplica los estilos. 

selector:pseudoclase {
    propiedad: valor;
}

Permiten crear páginas más dinámicas sin necesidad de utilizar JavaScript para cada efecto visual.

03 - Interacción

Pseudoclase :hover

Se utiliza cuando el usuario coloca el cursor del mouse sobre un elemento. Es muy común en botones y enlaces. 

a:hover {
    color: red;
    text-decoration: underline;
}
04 - Interacción

Pseudoclase :active

Se aplica mientras el usuario mantiene presionado un elemento interactivo, como un botón o un enlace. 

button:active {
    background: darkblue;
    transform: scale(0.95);
}
05 - Formularios

Pseudoclase :focus

Se utiliza cuando un elemento recibe el enfoque, por ejemplo, cuando seleccionamos un campo de formulario. 

input:focus {
    border: 2px solid blue;
    outline: none;
}
06 - Posición

:first-child y :last-child

Estas pseudoclases permiten seleccionar el primer o último elemento hijo dentro de un contenedor. 

li:first-child {
    color: green;
}

li:last-child {
    color: red;
}
07 - Posición

Pseudoclase :nth-child()

Permite seleccionar elementos según su posición dentro de un grupo. También permite seleccionar posiciones pares o impares. 

li:nth-child(2) {
    color: blue;
}

li:nth-child(even) {
    background: #eee;
}
08 - Formularios

:checked y :disabled

:checked selecciona controles marcados, mientras que :disabled selecciona elementos de formulario deshabilitados. 

input:checked {
    accent-color: green;
}

input:disabled {
    background: #ddd;
}
09 - Concepto

¿Qué son los pseudoelementos?

Los pseudoelementos permiten aplicar estilos a una parte específica de un elemento HTML o insertar contenido decorativo sin modificar el HTML. 

selector::pseudoelemento {
    propiedad: valor;
}
10 - Contenido

Pseudoelemento ::before

Permite insertar contenido antes del contenido real de un elemento. Se utiliza para agregar símbolos y elementos decorativos. 

h2::before {
    content: "★ ";
    color: orange;
}
11 - Contenido

Pseudoelemento ::after

Permite insertar contenido después del contenido de un elemento. Es útil para agregar símbolos y decoraciones. 

h2::after {
    content: " ✓";
    color: green;
}
12 - Texto

::first-letter y ::first-line

Permiten modificar la primera letra o la primera línea de un texto. 

p::first-letter {
    font-size: 30px;
    color: blue;
}

p::first-line {
    font-weight: bold;
}
13 - Texto

::selection

Permite cambiar los colores del texto cuando el usuario lo selecciona con el mouse o el teclado. 

::selection {
    background: yellow;
    color: black;
}
14 - Formularios

::placeholder

Permite modificar la apariencia del texto de ejemplo que aparece dentro de los campos de formulario. 

input::placeholder {
    color: gray;
    font-style: italic;
}
15 - Comparación

Diferencias entre ambos

Las pseudoclases seleccionan elementos según su estado o condición.

Los pseudoelementos permiten seleccionar partes específicas de un elemento o insertar contenido decorativo. 

button:hover {
    color: red;
}

p::first-letter {
    color: blue;
}
16 - Recomendaciones

Consejos para utilizar pseudoclases y pseudoelementos

  • Utiliza :hover para mejorar la interacción.
  • Utiliza :focus para destacar los formularios.
  • Usa :nth-child() para seleccionar posiciones.
  • Utiliza ::before para agregar contenido decorativo.
  • Utiliza ::after para complementar elementos.
  • Organiza tus selectores CSS.

Las pseudoclases y los pseudoelementos permiten crear páginas web más interactivas, organizadas y atractivas.
